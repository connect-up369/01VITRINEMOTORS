# Vitrine Motors — demonstração

## Publicar no GitHub Pages
1. Extraia este ZIP no computador. Não envie apenas o ZIP ao GitHub.
2. Crie um repositório e envie TODO o conteúdo extraído, preservando a pasta assets.
3. index.html deve estar na raiz do repositório, junto dos CSS e JS.
4. Abra Settings > Pages > Build and deployment > Deploy from a branch.
5. Selecione main e /(root), salve e aguarde o GitHub mostrar o endereço publicado.
6. Abra esse endereço no celular, confira imagens, vídeos e botões e compartilhe o LINK do site.

O GitHub Pages normalmente publica o site abertamente. Para uma apresentação confidencial, use hospedagem com controle de acesso. Um repositório privado não torna automaticamente o Pages privado.
GitHub Pages é adequado para esta demonstração estática; a operação comercial deve usar hospedagem apropriada às regras do provedor.

## Conteúdo
13 veículos ilustrativos; 7 galerias estáticas de quatro ângulos e 6 experiências com movimento, incluindo Ferrari prata e azul; busca e favoritos no navegador. Sem backend, estoque real, painel de lojista ou sincronização de vendas.
Os dados dos carros estão em showroom.js. Manter a pasta assets junto ao HTML.
Fontes usam Google Fonts, com fontes alternativas locais do navegador.

## Material visual
Imagens de estúdio geradas por IA; não são fotografias de estoque real. A Porsche é uma sequência de imagens animadas, não filmagem nem 3D navegável.
O vídeo Jesko foi fornecido como referência pelo usuário; é material de terceiros sem licença comercial verificada. Antes de publicação externa, confirme a autorização do titular ou substitua por material autorizado. Os créditos não equivalem a uma licença.
